04 / HOW APPLICATIONS USE IT

New time coordinate. Same reliable foundations.

The SDK supplies the date arithmetic, conversion, formatting, 28-day calendar model, and reporting model. Your app supplies whatever UI framework it prefers.

import {
  now, calendarGrid, fromLunar,
  add, startOf, difference, report
} from './buddhist-calendar.mjs';

const today = now({ mode: 'phase' });
const grid = calendarGrid(Date.now());
const utc = fromLunar({
  cycleId: today.cycleId,
  day: 7, hour: 12
});
const nextWeek = add(utc, 1, 'week');
const monthStart = startOf(utc, 'month');
